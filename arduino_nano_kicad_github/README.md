# Placa basada en ATmega328 (KiCad)

Proyecto de diseño electrónico en KiCad, con esquema y circuito impreso de una placa basada en el microcontrolador **ATmega328-M**.

## Archivos

- `prueba.kicad_pro` — configuración del proyecto.
- `prueba.kicad_sch` — esquema electrónico.
- `prueba.kicad_pcb` — diseño de la placa PCB.

## Cómo abrirlo

1. Descarga o clona este repositorio.
2. Abre `prueba.kicad_pro` con KiCad.
3. Usa el editor de esquemas o PCB para revisar y modificar el diseño.

> **Estado:** Proyecto de diseño. No se han verificado aquí la compatibilidad total con Arduino Nano, las reglas eléctricas (ERC), las reglas de diseño (DRC) ni el funcionamiento de una placa fabricada.
